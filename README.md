# 🏠 Rumper — Property Due-Diligence Companion

> **"Sudah suka rumahnya? Cek dulu risiko lokasinya."**  
> Rumper is a calm, evidence-led property due-diligence companion tailored for Indonesian homebuyers. It turns location uncertainty into concrete, actionable steps.

---

## 🌟 Key Features

- **📍 Location Risk Analysis**: Interactive scoring for environmental, infrastructure, and legal risks.
- **🚗 Commute & Accessibility**: Evaluate daily routes, traffic patterns, and distance to key hubs.
- **🏢 Public Facilities Mapping**: Discover nearby schools, hospitals, transit, and markets.
- **📋 Gamified Due-Diligence Checklist**: Step-by-step verification checklist before making a deposit or decision.
- **🗺️ Interactive Map Panel**: Real-time spatial evidence powered by Leaflet & OpenStreetMap.

---

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Mapping**: [Leaflet](https://leafletjs.org/) & `react-leaflet`
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- `npm` or `pnpm`

### Installation & Run Locally

```bash
# Clone the repository
git clone https://github.com/sandezign/rumper-web-gamification.git

# Navigate into project directory
cd rumper-web-gamification

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser at `http://localhost:5173` (or the port shown in terminal).
